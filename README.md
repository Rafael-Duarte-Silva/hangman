# Historia / Explicação

Durante este período da faculdade, curiosamente me deparei novamente com um desafio que já havia enfrentado no início da minha jornada na programação, ainda durante o ensino técnico: desenvolver um **Jogo da Forca**.

Ao perceber essa coincidência, decidi transformar o projeto em uma oportunidade para revisitar aquele desafio e comparar minha forma de pensar e escrever código depois de alguns anos de aprendizado e experiência.

A ideia deste repositório é justamente registrar essa evolução: **como eu resolvia um mesmo problema no início da minha trajetória e como o abordo atualmente**, observando mudanças na organização, estrutura, lógica e estilo de programação.

Para comparação, o projeto original desenvolvido durante o ensino técnico está disponível aqui:

**Repositório original (update forca 5):**
https://github.com/Rafael-Duarte-Silva/Jogo-da-forca

## Observação sobre o código antigo

O código da versão antiga foi alterado **o mínimo possível**, apenas para que pudesse ser compilado e executado em **Linux** e para corrigir problemas que impediam seu funcionamento.

Por sua baixa legibilidade, essas alterações foram realizadas **com o auxílio de uma IA**, principalmente para identificar e corrigir problemas de compatibilidade e erros que impediam a execução do código.

Mesmo com essas alterações, **alguns bugs e comportamentos inesperados permanecem presentes**. Isso foi feito de forma intencional, buscando preservar o máximo possível da implementação original e permitir uma comparação mais fiel entre o código daquela época e a versão atual.
